# Rosterly – Landing Page

A responsive landing page for **Rosterly**, a sample SaaS product that helps cafés and restaurants build weekly staff schedules. Built as the Sankar Group front-end internship assignment.

**Live site:** https://ritikshachavan.github.io/rosterly-landing-page/

## Sections

- Navigation bar with logo, section links, "Get started" button and a mobile menu
- Hero with headline, call-to-action buttons and an interactive sample rota
- Features (3 cards with icons)
- How it works (3 steps)
- Pricing (3 plans: Starter, Team, Chain)
- Contact / demo request form and footer

## Interactions

- Navigation links and buttons scroll smoothly to the matching section
- Menu button opens and closes the navigation on small screens
- Click a shift in the hero rota to cycle it between Open, Covered and Off
- Pricing buttons scroll to the form and pre-select the chosen plan
- Demo form validates name, email and plan, shows error messages, and shows a success message on submit (no backend)

## Technologies

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries)
- Vanilla JavaScript
- Google Fonts (Bricolage Grotesque, DM Sans)
- Hosted on GitHub Pages

No frameworks, libraries or build tools are used.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser. No installation is needed.
